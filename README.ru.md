# macOS_sucks

[English](README.md) | **Русский**

Каждый сентябрь Apple выкатывает новую кучу. На macOS это «переосмысленные» Системные настройки, в которых чтобы выключить трекпад надо три раза помолиться и найти тумблер, спрятанный за тумблером. На iOS — тот же телефон, только кнопка «назад» снова в другом углу, а батарея живёт меньше, зато Dynamic Island теперь *ещё круглее*.

И люди стоят в очереди. Платят как за почку. Потом в Твиттере (простите, в «X», это тоже прогресс) пишут: «actually, once you get used to it…» Да, как к геморрою. Потом покупают чехол за 80 баксов, чтобы не поцарапать аллюминий, который и так не должен царапаться, потому что *premium*. Потом обновляются до новой мажорной версии и обнаруживают, что Finder по-прежнему не умеет создать текстовый файл по правому клику на пустом месте. Двадцать. Четвёртый. Год. Подряд.

iOS-юзеры в это время счастливо жмут «разрешить отслеживание» 14 раз в день и верят, что «это для вашей безопасности». Да. Безопасности акционеров. Пока Siri как десять лет назад делает вид, что не расслышала, а калькулятор в очередной раз переехали, чтобы ты случайно не нашёл, как посчитать чаевые без подписки.

macOS-юзеры кивают: «зато экосистема». Экосистема — это когда одно устройство не умеет то, что другое умеет через кабель за 70 долларов, а AirDrop не видит мак, который лежит на соседней подушке. Зато если случайно зажать два пальца не под тем углом, окно улетает в Mission Control, и ты чувствуешь себя глупым. Это фича. Ты просто не понял ви́дение.

И главное: им это нравится. Они сами себе объясняют, что так и должно быть. Что «так задумано». Что Windows — это для бедных, Android — для таксистов, а страдание с SIP, Gatekeeper, «разрешите универсальный доступ», «разрешите мониторинг входных данных», «разрешите расширению Finder», «нет, не тому AutoText, а вот этому, удалите минусом, добавьте плюсом» — это и есть *it just works*.

Это приложение существует, потому что «просто работает» не умеет ни вставить текст нормальными клавишами в Horizon, ни сделать пустой `.txt` в текущей папке, ни свайпнуть двумя пальцами без семи галочек в настройках приватности. Название честное. Если тебе обидно — ты узнал себя. Если смешно — поставь и пользуйся. Если и то и другое — добро пожаловать, ты и есть целевая аудитория.

Меню-бар утилита: текстовые макросы по глобальной горячей клавише, свайпы двумя пальцами и пункт Finder **«Создать текстовый документ»** — в том числе по правому клику на пустом месте.

Текст макроса набирается настоящими нажатиями клавиш, не через ⌘V. Так он доходит и до Omnissa Horizon Client. Да, для этого на Mac в 2026 году нужна отдельная программа. Мы тоже в шоке.

Интерфейс может быть **русским или английским**. В боковой панели приложения, в разделе «Язык», выбери «Как в системе», «Русский» или «English».

## Что умеет

- Глобальные макросы: записал сочетание — в любом поле набирается заготовленный текст.
- Если сейчас русская раскладка, а в тексте есть латиница, раскладка на время набора переключается на английскую и возвращается обратно. Сама macOS об этом, конечно, не подумала.
- Свайп двумя пальцами влево/вправо в выбранных приложениях (по умолчанию Finder и Системные настройки) = ⌘] / ⌘[.
- В контекстном меню Finder: **Создать текстовый документ**. На папке она разворачивается в том же окне, файл появляется внутри. Windows умела это, когда Джобс ещё носил водолазку.

## Требования

- macOS 14 или новее
- Apple Silicon (`arm64`)

## Установка готовой сборки

Без Xcode и без `make`. Просто zip из [Releases](https://github.com/1richardsmi/macOS_sucks/releases/latest).

1. Скачай `macOS_sucks-1.0-arm64.zip`.
2. Распакуй.
3. Перетащи `macOS_sucks.app` в `~/Applications` (или `/Applications`).
4. Правый клик по приложению → **Открыть**. Gatekeeper возмутится: подпись самодельная, не из App Store. Жми **Открыть** всё равно. Обычного двойного клика в первый раз часто мало.
5. Дальше — паломничество по галочкам ниже.

Если macOS всё равно не пускает, в Терминале:

```bash
xattr -cr ~/Applications/macOS_sucks.app
```

Потом снова правый клик → Открыть.

## Установка из исходников

Ещё понадобятся [Xcode Command Line Tools](https://developer.apple.com/download/all/?q=command%20line%20tools).

```bash
xcode-select -p || xcode-select --install
```


```bash
git clone https://github.com/1richardsmi/macOS_sucks.git
cd macOS_sucks
make
```

`make` собирает приложение и копирует его в `~/Applications/macOS_sucks.app`.

Запустить сразу после сборки:

```bash
make run
```

Или открыть `~/Applications/macOS_sucks.app` из Finder.

Подпись — локальный самоподписанный сертификат (файлы в `.certs/`, в git не попадают). Из‑за этого macOS считает каждое приложение «своим»: после обновления пути или сертификата доступ в Настройках иногда нужно выдать заново. *It just works*, повтори ещё раз, вдруг поможет.

## Первый запуск: разрешения

macOS не даёт слать клавиши и жесты без паломничества по чекбоксам. Это не баг, это «конфиденциальность»: система не доверяет программе, которую ты только что скачал или собрал сам.

1. **Универсальный доступ**  
   Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → включи `macOS_sucks`.  
   Если тумблер уже был от старой копии: «−», затем «+» и выбери текущий файл `~/Applications/macOS_sucks.app`. Перезапусти приложение.

2. **Мониторинг входных данных**  
   Нужен для свайпов двумя пальцами. Туда же добавь `macOS_sucks`, если жест не срабатывает.

3. **Расширение Finder**  
   В приложении открой раздел **Finder** → **Открыть настройки расширений Finder** → включи **macOS_sucks Finder**.  
   После этого пункт «Создать текстовый документ» можно включать и выключать в самом приложении.

4. Если система спросит, можно ли управлять Finder — разреши. Иначе папка после создания файла может не развернуться. Четвёртая галочка. Ты ещё здесь? Молодец, ты настоящий пользователь Apple.

## Как пользоваться

1. Добавь макрос, введи текст, нажми **Записать** и нажми сочетание (удобнее Control+Option+клавиша, чем Command+Option).
2. Кликни в нужное поле, нажми сочетание и отпусти клавиши. Набор начнётся только когда модификаторы отпущены.
3. Свайпы: в разделе **Свайп двумя пальцами** оставь Finder / Настройки или добавь другие приложения.
4. Finder: правый клик по пустому месту или по папке → **Создать текстовый документ**.
